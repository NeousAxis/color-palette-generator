## ✨ Features

- **5 palette modes** — Random, Monochromatic, Analogous, Complementary & Triadic
- **One-click copy** — Click any color swatch to copy its HEX code
- **Copy entire palette** — Export all hex values at once
- **Keyboard shortcut** — Press `Space` to generate a new palette instantly
- **Fully responsive** — Works seamlessly on desktop, tablet & mobile
- **Smooth animations** — Powered by [Motion](https://motion.dev) (Framer Motion)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/NeousAxis/color-palette-generator.git

# Navigate to the project
cd color-palette-generator

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will be running at `http://localhost:3000`.
